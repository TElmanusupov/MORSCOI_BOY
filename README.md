# ⚓ Морской бой

Учебный проект на HTML, CSS и JavaScript.

## 1. Архитектура программы

Используется архитектурный паттерн **MVC**:

- **Model** — хранит данные и правила игры:
  - `Ship` — корабль;
  - `ShipFactory` — создание флота;
  - `Board` — игровое поле;
  - `Game` — управление состоянием игры.
- **View** — класс `DOMRenderer`. Он отображает модель в HTML.
- **Controller** — `GameController`. Он принимает действия пользователя и запускает игровую логику.

Схема:

User → Controller → Model → View → Screen

## 2. Использованные паттерны

### Factory Pattern
`ShipFactory` создаёт флот по единому шаблону. Это позволяет не создавать каждый корабль вручную.

### MVC
Позволяет отделить игровую логику от визуального интерфейса. Поэтому дизайн можно менять, почти не затрагивая правила игры.

## 3. Визуальный слой

`style.css` отвечает за:
- тёмный морской дизайн;
- два игровых поля 10×10;
- отображение кораблей;
- попадания и промахи;
- адаптацию под телефон;
- анимацию наведения;
- информационные карточки.

## 4. Как запустить

Открой файл `index.html` в браузере.

Интернет для работы игры не требуется.

## 5. Правила

У каждого игрока флот из:
- 1 линкора — 4 клетки;
- 2 крейсеров — 3 клетки;
- 3 эсминцев — 2 клетки.

Корабли не соприкасаются друг с другом.

Игрок стреляет по правому полю. После промаха ход переходит компьютеру. Попадание позволяет сделать ещё один выстрел.

Компьютер после попадания старается проверять соседние клетки.
